# MICモーグルホームページ リニューアルプロジェクト

現行サイト（mogul-mic.com）を Apple 風のデザインに刷新するプロジェクトです。
試作環境は GitHub Pages（vanwhist/mic-site-mockup）。
レンタルサーバーは使わず、GitHub Pages 単体で運用します。

## ⚠️ ドメインの使い分け（最重要・間違えやすい）

- **`https://mogul-mic.com/` … MICの公式ホームページ。対外的に案内するURLは必ずこちら。**
  YouTube・SNS・チラシ・お客様や関係者への案内など、外部に出すURLはすべて `.com` を使う。
- `https://mogul-mic.site/` … リニューアルの**試作・確認用**。サイト上部に「RAFU / DRAFT ー トップページ試作（.site環境用・非公開）」のバッジが出ている通り、まだ一般公開する段階ではない。**外部に出すURLとして使わないこと。**
- リニューアルが完成し「`.com` を新サイトに切り替える」という判断がVan様からなされるまで、この使い分けは変わらない。

> 2026/8/8、YouTubeチャンネルの説明文とリンクに誤って `.site` を記載し、Van様のご指摘で `.com` へ修正した。
> 原因は本ファイルに「公開予定ドメインは `mogul-mic.site`」と書かれていたこと。同じ間違いを繰り返さないこと。
